# On a Cut 刷脂助手

手机端使用的 30 天刷脂记录工具，单文件 `index.html`，无需安装和构建。

需求、规则和功能模块的完整说明见 [docs/SPEC.md](docs/SPEC.md)。源码在 `src/on-a-cut.html`，`index.html` 由 `sh build.sh src/on-a-cut.html index.html` 生成。

## 怎么用

- 直接用手机浏览器打开 `index.html`；或在仓库 Settings → Pages 里把分支设为发布源，用 GitHub Pages 的网址访问，并“添加到主屏幕”。
- 数据保存在浏览器本地（localStorage）。换设备时在“准则”页导出 / 导入备份。

## 功能

| 页面 | 作用 |
| --- | --- |
| 今天 | 切换状态 A / B / C，查看进食窗口倒计时；按“掌 / 拳 / 勺 / 段”一键记录，四条卷尺式进度条显示蛋白、碳水、脂肪、热量与目标区间；自动提示还差几掌肉、还能吃几拳主食；也可以直接描述食物（如“一个手掌大的章鱼”）由 AI 估算营养，此功能仅在 Claude 发布的页面里可用，独立打开 `index.html` 时改为手动填克数 |
| 对冲 | 点一款甜点先预演，用三张数字卡片给出今晚主食几拳、蛋白几掌、蔬菜几捧，以及超出部分分几天摊平 |
| 记录 | 本周训练打卡、训练笔记、晨起体重与腰围、7 日均重趋势图、30 天打卡格 |
| 准则 | 优化后的规则、可调的每日额度和每周安排、一键复制“AI 交接档案”（含近 7 天数据） |

## 优化后的准则（相对原档案的改动）

1. **碳水上调约 25g，让克数和热量对得上。** 原方案的三大营养素合计只有约 1380 kcal（训练日）/ 1190 kcal（休息日），比目标热量低 150–250 kcal。
2. **休息日蛋白不下调**，全周 100–110g（约 1.6–1.7 g/kg），底线 85g。
3. **蛋白底线优先于断食窗口**：关窗后仍低于底线，水冲 1 勺蛋白粉。
4. **对冲 = 当晚调整 + 多日摊平**：先保蛋白，再从主食和油里腾额度；仍超出的部分用 2–4 天各少半拳主食消化，不加练。
5. **用 7 日均重判断进度**，目标每周 −0.3~0.6 kg；过快加 1 拳主食，连续 2 周持平再减半拳或多走 2000 步。
6. **牛奶和烹调油要记账**（250ml 全脂牛奶 ≈ 150 kcal，1 茶匙油 ≈ 45 kcal）。

| | 蛋白 g | 碳水 g | 脂肪 g | kcal |
| --- | --- | --- | --- | --- |
| 训练日 A / B | 100–110 | 165–180 | 42–48 | 1500–1600 |
| 休息日 C | 100–110 | 125–140 | 42–48 | 1350–1450 |

实物换算：1 掌瘦肉 ≈ 30g 蛋白；1 拳主食 ≈ 33g 碳水；1/3 根法棍 ≈ 45g 碳水，半根 ≈ 70g；Bulk 蛋白粉 1 大勺 ≈ 23g 蛋白；无糖豆浆粉 1 袋 ≈ 6g 蛋白；蔬菜两捧起不限量。

> 热量目标按常见公式估算，属一般性健康建议。如有基础疾病、月经紊乱或持续乏力，请先咨询医生或注册营养师。
