# On a Cut 刷脂助手

手机上用的饮食与训练记录工具：按“掌、拳、勺”记录，自动计算每日热量和三大营养素目标。纯前端单文件，无需后端。

需求、计算规则和功能模块见 [docs/SPEC.md](docs/SPEC.md)。源码在 `src/on-a-cut.html`，`index.html` 由 `sh build.sh src/on-a-cut.html index.html` 生成。

## 部署到 GitHub Pages

1. 把包含 `index.html` 的分支合并到默认分支（或直接用当前分支）。
2. 仓库 Settings → Pages → Source 选 “Deploy from a branch”，选择分支和 `/ (root)`，保存。
3. 一两分钟后访问 `https://<用户名>.github.io/on-a-cut/`，在手机浏览器里“添加到主屏幕”。

每个访问者的数据只保存在自己浏览器的 localStorage 里，互不干扰。换手机或清理缓存前，在右上角“身体档案与设置”里导出备份 (JSON)，之后可恢复。

## 功能

- **首次引导**：填性别、年龄、身高、体重、目标和每周训练次数，按 Mifflin-St Jeor 公式算出每日热量与蛋白、碳水、脂肪目标；也可手动设置。
- **今天**：剩余热量、三大营养素进度、按目标生成的参考餐单、一键记录、每餐一行评价。
- **对冲**：想吃甜点时先预演，给出当晚主食、蛋白、蔬菜的份数和摊平方案。
- **记录**：训练打卡、体重趋势与目标进度、本周饮食统计、最近 30 天。
- **准则**：按你的目标生成的规则说明；一键复制给 AI 的交接档案。

用一句话描述食物并由 AI 估算营养的功能，只在 Claude 发布的页面里可用；GitHub Pages 上请手动填克数或热量。

> 计算结果属一般性健康建议，不能替代医疗意见。孕期、哺乳期、有基础疾病或进食障碍史，请先咨询医生或注册营养师。
